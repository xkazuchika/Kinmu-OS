# v0.7 Japanese UI language guide

## Principles

- 画面名だけでなく「この画面で何を完了するか」を一文で示す
- ボタンは対象と結果を表す動詞を使う
- 内部値は補足にし、日本語の業務状態を主表示にする
- エラーは責任追及ではなく、原因と解消手順を示す
- 「こちら」「上記」ではなく対象名を使う

## Status labels

| Internal            | Primary Japanese | Guidance                       |
| ------------------- | ---------------- | ------------------------------ |
| `pending`           | 審査待ち         | 審査一覧への導線を示す         |
| `approved`          | 承認済み         | 承認日時または反映状態を示す   |
| `rejected`          | 却下             | 理由と再申請可否を示す         |
| `open`              | 編集中           | 変更可能であることを示す       |
| `closed`            | 締め済み         | リビジョンと再開要否を示す     |
| `reopened`          | 再開中           | 旧リビジョンと再締めを示す     |
| `within_request`    | 申請範囲内       | 法令判定ではないことを補足する |
| `exceeded_request`  | 申請時間を超過   | 申請と実績の確認先を示す       |
| `no_actual`         | 勤務実績なし     | 打刻または修正の確認先を示す   |
| `unapproved_actual` | 未申請の勤務実績 | 申請または打刻の確認先を示す   |

## Action labels

| Avoid      | Use                               |
| ---------- | --------------------------------- |
| OK         | 内容を確認して閉じる              |
| 実行       | 勤怠CSVを生成                     |
| 確定       | 2026年7月を締める                 |
| 送信       | 休暇申請を提出                    |
| 保存       | 勤務ルールを保存                  |
| 詳細       | 勤務実績を見る                    |
| キャンセル | 編集を続ける / 変更を破棄して戻る |

短い一覧行で「見る」「編集」を使う場合は、アクセシブルネームへ対象名を含める。

## Form annotations

- 必須: `必須`
- Optional: `任意`
- Unit: 入力の直後に`分`、`時間`、`日`
- Example: `例: 09:00`
- Range: `10〜180分`
- Impact: `適用開始日以降の勤務予定に反映されます`
- Disabled: `対象月が締め済みのため変更できません`

placeholderを唯一の説明にしない。入力欄の幅だけで形式や最大長を伝えない。
