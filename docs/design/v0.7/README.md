# Kinmu-OS v0.7 UI design references

v0.7では、画面を開いて3秒程度で「ここで何をするか」「現在どの状態か」「次に何をするか」を判断できることをデザイン基準とする。

## Concept references

- `admin-home-concept.png`: 役割別ツリーナビゲーション、対象月、次にやること、月次状況の基準
- `attendance-list-concept.png`: 100名規模の一覧、条件、件数、対応要否、行操作の基準
- `work-rule-form-concept.png`: 入力幅、ラベル、単位、例、制約、未保存、影響確認の基準
- `mobile-menu-concept.png`: 最大二階層の全機能メニュー、44px操作、モバイル下部ナビゲーションの基準

画像はレイアウト、密度、配色、余白、操作階層を示す設計資料であり、UIそのものへ埋め込まない。実際の文言、入力、表、アイコン、状態はReactとCSSで実装する。

## Design documents

- `design-system.md`: デザイントークン、構造、コンポーネント、レスポンシブ規則
- `screen-catalog.md`: 主要画面、役割、目的、完了条件、次の操作
- `ux-audit.md`: v0.6の不足とv0.7の受入基準
- `language-guide.md`: 日本語の状態名、操作名、入力説明

## Visual direction

- 背景は真白、サイドバーのみごく薄い寒色
- 深いネイビーの本文と、限定したコバルトブルーの主要操作
- 4px基礎の余白と、意味のある細い境界線
- 角丸は8〜12px、影はダイアログ等の浮いた面だけ
- カードを重ねず、余白、見出し、行、表で情報の関係を示す
- 状態はアイコンと日本語を併用し、色だけに依存しない
- 主要操作は通常一つとし、対象と結果を動詞で示す
