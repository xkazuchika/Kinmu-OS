# v0.7 design system

## Color

| Token          | Value     | Usage                                    |
| -------------- | --------- | ---------------------------------------- |
| canvas         | `#ffffff` | 認証済み画面の背景                       |
| sidebar        | `#f5f8fd` | デスクトップサイドバー、モバイルドロワー |
| surface-subtle | `#f4f8fe` | フィルター、選択、補足面                 |
| text           | `#102341` | 見出し、本文                             |
| text-muted     | `#536174` | 目的文、補足、メタ情報                   |
| border         | `#d7e0eb` | 行、セクション、入力                     |
| accent         | `#1456d8` | 現在地、主要操作、リンク                 |
| success        | `#13734b` | 完了                                     |
| warning        | `#835a00` | 対応要、未保存                           |
| danger         | `#b42318` | エラー、未退勤、破壊的操作               |

背景色は真白を維持し、ベージュやクリームへ変更しない。グラデーション、ガラス表現、装飾的な光彩は使用しない。

## Typography

- 日本語: `Inter`, `Hiragino Sans`, `Yu Gothic UI`, `Yu Gothic`, `Meiryo`, sans-serif
- ページ見出し: 32〜36px、700〜760、行高1.25
- セクション見出し: 20px、700
- 本文・入力: 16px、行高1.65
- ナビゲーション・ボタン: 14〜15px、650〜700
- 補足・表見出し: 12〜14px
- 内部状態値だけを主表示にせず、日本語の業務名を優先する

## Spacing and containers

- 基礎単位: 4px
- ページ左右: 32px、768px以下は16px
- ページ概要と本文: 24px
- 独立セクション: 32〜40px
- フォーム項目: 16〜20px
- ラベルと入力: 6〜8px
- 関連操作: 8〜12px
- 表セル: 縦12px、横16px
- 標準本文: 最大72rem
- フォーム本文: 最大44rem

## Form controls

| Size   | Maximum width | Typical values                 |
| ------ | ------------- | ------------------------------ |
| short  | 12rem         | 社員番号、日付、時刻、分数     |
| medium | 24rem         | 氏名、名称、メール             |
| long   | 36rem         | 検索、長い識別子               |
| full   | 100%          | 一覧フィルター、複合レイアウト |

主要入力とボタンの高さは44px以上とする。textareaは用途別に3、5、8行を使い分け、縦方向のサイズ変更を許可する。幅やplaceholderだけで形式を伝えない。

## Component families

- `PageHeader`: パンくず、目的、対象、状態、主要操作、ガイド
- `TaskContext`: 前提、完了条件、阻害理由
- `PrimaryActionGroup`: 主要、補助、破壊的操作
- `StatePanel`: 未設定、0件、検索0件、阻害、締め済み、取得失敗
- `ResultSummary`: 保存対象、反映状態、次の確認先
- `SubjectContext`: 対象日・月、従業員・部署、タイムゾーン、締め状態
- `ListHeader`: 総件数、表示件数、条件、並び順、状態要約
- `Field`: 必須・任意、単位、説明、例、制約、エラー、意味的サイズ
- `Disclosure`: 詳細設定の段階表示
- `NavigationTree`: 役割別カテゴリ、現在地、自動展開

## Container model

ページは開いたレイアウトを基本とし、全領域をカードへ入れない。カードは一つの独立した状態または確認対象にだけ使用する。一覧は表、処理待ちは行、工程は進捗リスト、設定は最大44remのフォームを用いる。

## Responsive

- 768px超: 左サイドバー、上部バー、デスクトップ表
- 768px以下: 下部ナビゲーション4項目以内＋「すべて」、表は主要項目カード
- 320px以上でページ横スクロールを発生させない
- ドロワー、ダイアログはフォーカスを閉じ込め、終了後に開始元へ戻す

## Motion

- カテゴリ展開、ドロワー、状態更新だけに150〜200msの短い遷移を使用する
- `prefers-reduced-motion`では不要な遷移を停止する
- 読込中に偽の進捗率を表示しない
