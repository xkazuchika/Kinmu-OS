# Kinmu-OS v0.7.0 リリース候補レビュー

- 対象バージョン: 0.7.0
- 対象変更: `improve-app-wide-guidance`
- 予定タグ: `v0.7.0`（コミット、CI成功、OpenSpec同期・アーカイブ後に同じコミットへ付与する）

## 変更概要

v0.7.0は既存業務機能を変えず、初めて担当する利用者が「ここで何をするか」「次に何をするか」を判断しやすくする全体UX更新です。

- 管理者・従業員別の最大二階層ツリーメニューとモバイルの「すべて」ドロワー
- 全主要画面の現在地、目的、対応ガイド
- 初期設定・月次業務の進捗と阻害理由
- 4px基礎の余白、44px操作高さ、用途別入力幅、説明・例・単位・影響
- 未設定、検索0件、阻害、取得失敗、成功結果の状態別表示
- 未保存変更の移動・終了警告と非同期操作状態
- 対象月、条件、状態、件数、固定見出し、320pxカード一覧
- 許可済み条件だけを保持する利用ガイド往復

## データと更新

v0.7.0ではDB migrationを追加しません。v0.6.0のDBをそのまま使用し、アプリと配布物だけを更新します。更新前バックアップは通常どおり取得してください。

更新後に次を確認します。

1. 所有者、労務管理者、従業員でログインできる。
2. 役割別メニューに許可された機能だけが表示される。
3. 管理者ホームに初期設定または月次業務の次工程が表示される。
4. 勤怠一覧で対象月と条件を変更でき、月次締め状態が一致する。
5. 各画面の利用ガイドを開き、元の条件付き画面へ戻れる。
6. 主要フォームの入力幅、説明、未保存警告、保存結果が表示される。

## ロールバック

DBスキーマ変更はないため、アプリイメージをv0.6.0へ戻せます。ただし、更新前バックアップとCompose設定を保管し、切り戻し後にログイン、勤怠、締めリビジョン、給与runを確認します。v0.7.0の画面状態はブラウザーの一時保存だけで、DBへ新しい形式を保存しません。

### デザイン忠実度

生成コンセプトと、同じ1488×1058または320×844で取得した本番ビルドの実画面を比較しました。

| 比較点               | 確認結果                                                                                             |
| -------------------- | ---------------------------------------------------------------------------------------------------- |
| キャンバスと色       | 白い業務キャンバス、淡い青のサイドバー、濃紺の本文、コバルトの主要操作を一致させた                   |
| 情報階層             | 現在地、画面目的、対象・状態、完了条件、主要操作の順で、見出しを読み飛ばしても業務を判断できる       |
| ツリーナビゲーション | 最大二階層、現在カテゴリの自動展開、現在項目の青い面と左線、役割別項目をデスクトップとモバイルで確認 |
| 入力サイズ           | 44px以上の操作高とshort/medium/longの幅を確認し、勤務ルールは基本項目と影響説明を二列へ整理          |
| 一覧                 | 条件、件数、月次状態、固定見出し、50件ページング、320pxカード変換を確認                              |
| 空・阻害・成功状態   | 読込中、検索0件、未設定、締め阻害、保存成功が別の面と具体的な次操作で表示される                      |
| モバイルメニュー     | 背景遮蔽、44px以上の閉じる操作、フォーカストラップ、Escape、現在カテゴリを確認                       |
| 主要操作の優先度     | 画面ごとに青い主要操作を原則一つとし、再読込や取消は枠線またはテキスト操作へ分離                     |

コンセプトは情報量の少ない例示データ、実画面は月次締め・審査・給与連携を含む実データであるため、実画面の縦方向は長くなります。主要な判断順序、余白階層、操作優先度は維持し、50件単位のページングで過度な長さを抑えます。

詳細は [v0.7テストシナリオ対応表](v0.7-test-scenario-matrix.md) に記録します。

## 既知の制限

- 時間単位休暇、多段承認、代理申請、自動法令判定は未対応です。
- 給与・税・社会保険・割増賃金の計算や給与ソフトAPI同期は行いません。
- ブラウザー履歴による未保存警告はブラウザー標準確認を使い、アプリ内リンクは共通確認ダイアログを使います。
- 320pxの複雑な一覧は主要情報をカード表示しますが、詳細値が多い画面では縦方向が長くなります。

## リリース判定

タグとGitHub Releaseは、全テスト成功、視覚確認、OpenSpecの差分仕様同期・アーカイブ、最終コミットとCI成功を確認した後に作成します。
