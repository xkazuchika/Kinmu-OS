# 打刻・勤務実績・プロフィール

対象バージョン: 0.8.0

## 対象役割と開始画面

対象役割は従業員です。ログイン後のホームから当日の打刻を行い、「勤務実績」と「プロフィール」で自分の情報を確認します。事前に管理者が従業員台帳と利用者を紐付けている必要があります。

## 出勤・退勤・休憩

1. 業務開始時に「出勤する」を選びます。
2. 休憩開始時に「休憩を開始」、再開時に「休憩を終了」を選びます。
3. 業務終了時に「退勤する」を選びます。
4. ホームの状態と時刻が変わったことを確認します。

打刻は出勤、休憩開始、休憩終了、退勤の順序で行います。二重出勤や、出勤前の退勤など不正な順序は保存されません。

## 勤務実績

1. 「勤務実績」を開きます。
2. 表示する月を選び、日ごとの打刻、実労働、残業を確認します。
3. 誤りがある場合は「修正を申請」を選びます。

詳しい申請方法は[勤怠修正の申請と審査](attendance-corrections.md)を参照してください。

## プロフィール

「プロフィール」では社員番号、所属、雇用区分などを確認し、連絡先メールアドレスと電話番号を更新できます。氏名や所属の変更は管理者へ依頼してください。

休暇の残高確認と申請は[休暇申請・審査・欠勤確定](leave-requests.md)を参照してください。

## 画面の目的

従業員が当日の状態を確認し、次に可能な打刻を記録して、自分の月別勤務実績を確認します。

## 入力項目

打刻は表示された操作を選びます。プロフィールでは任意の連絡先メールと電話番号、勤怠修正では変更後の時刻と具体的な理由を入力します。

## 完了条件

業務終了時に状態が「退勤済み」になり、勤務実績に当日の打刻と集計が表示されれば完了です。

## 次の操作

誤りがあれば[勤怠修正の申請と審査](attendance-corrections.md)、休暇や残業予定があれば対応する申請画面へ進みます。

## トラブル対処

次の打刻が表示されない場合は現在の状態と直前の打刻を確認します。従業員情報が表示されない場合は管理者へ利用者との紐付けを依頼し、詳細は[トラブル対処](troubleshooting.md)を参照してください。

## 現行版の制限

時間単位休暇、自動法令判定、多段承認には対応していません。管理者代理申請は「申請履歴」で対象本人にも表示されます。通知はアプリ内だけです。集計と申請承認は法令や就業規則への適合を判定するものではありません。
