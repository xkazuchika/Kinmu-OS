# アプリ内通知

対象バージョン: 0.8.0

## 通知される操作

- 休暇、勤怠修正、残業・休日出勤を提出または再申請すると、現在の実担当者へ通知します。未割当の場合は、自己審査になる利用者を除いた所有者と労務管理者へ通知します。
- 申請が差し戻し・承認・却下されると、対象従業員へ通知します。
- 代理作成された申請の結果は、対象従業員と、現在も代理作成権限を持つ実際の作成者へ通知します。
- 審査待ちまたは差し戻し中の申請が取り消されると、現在の実担当者へ通知します。
- 再割当すると、新担当者へ審査依頼、旧担当者へ担当解除の通知を作成します。

通知には申請種別、対象日、版、代理作成有無など業務に必要な最小限の要約だけを保存し、申請理由・代理理由の全文や任意URLは保存しません。ケース版・操作・受信者の一意キーで同じ通知の重複を防ぎます。メールや外部サービスへの送信は行いません。

## 未読・既読と対象を開く

サイドメニューの「通知」に未読件数が表示されます。通知を選ぶと既読になり、現在の役割を再確認して本人申請または管理者審査へ移動します。「表示中をすべて既読」で現在読み込んだ未読通知をまとめて既読にできます。

通知後に再割当された、役割が変わった、利用者が無効になった、または対象状態が変わった場合は、開く時点の権限を再検査します。旧担当者には担当解除の最小履歴だけを残し、申請者、理由、差分、審査操作へ移動させません。対象従業員は「申請履歴」の本人向け詳細へ移動します。

## 現行版の制限

メール、Slack等への外部通知、時間単位休暇、自動法令判定、多段承認には対応していません。申請・承認は法令や就業規則への適合を判定するものではありません。
