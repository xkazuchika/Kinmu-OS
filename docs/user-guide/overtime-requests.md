# 残業・休日出勤申請

対象バージョン: 0.8.0

## 申請する

1. 「残業・休日出勤」を開き、現在の入力単位、事前申請、許容差異を確認します。
2. 勤務日、予定開始・終了、予定休憩、理由を入力します。終了が開始以前なら翌日として扱います。
3. 「勤務予定と申請分数を確認」を選び、勤務カレンダーから判定された残業・休日出勤区分、勤務予定、予定分数を確認します。
4. 内容が正しければ確認ダイアログから送信します。

入力時刻は設定された単位に合わせます。事前申請が必須の場合、予定開始後は申請できません。同じ時間帯の審査待ち・承認済み申請、24時間を超える範囲、休憩が時間帯以上の申請も受け付けません。

## 取消、差し戻し、再申請

「申請履歴」では審査待ち、差し戻し、承認済み、却下、取消済みと各改訂を確認できます。自分で取り消せるのは審査待ちまたは差し戻し中の申請です。差し戻し時は理由を確認し、予定時間、休憩、区分、理由を修正して再申請します。再申請は現在のポリシー、勤務予定、事前申請期限、入力単位、重複、締め状態を再検証します。

管理者が代理作成した自分の申請も同じ一覧で確認・修正・取消できます。対象従業員、実際の作成者、代理理由が分けて表示されます。締め済み月の提出・取消・差し戻し・再申請・審査はできないため、修正が必要なら管理者へ月次勤怠の再開を依頼します。

## 実績差異を確認する

承認された予定分数は勤怠実績へ加算されません。「勤務実績」で申請分、実績比較分、差分と次の状態を確認します。

- 申請内: 許容分数の範囲内です。
- 申請未満: 実績が申請より少ない状態です。
- 申請超過: 実績が申請と許容分数を超えています。
- 実績なし: 承認済み申請に対応する実績がありません。
- 未申請の実績: 実績はありますが承認済み申請がありません。

申請の審査結果は[アプリ内通知](notifications.md)、勤務実績の修正は[勤怠修正の申請と審査](attendance-corrections.md)も参照してください。

## 画面の目的

勤務予定と現在の申請ルールを確認し、所定時間外または休日の勤務予定を事前に審査へ提出します。

## 入力項目

勤務日、申請区分、予定開始・終了、予定休憩、理由を入力します。区分は未選択なら勤務カレンダーから自動判定されます。

## 完了条件

確認画面の予定分数と区分を確認して提出し、申請履歴に「審査待ち」が表示されれば完了です。

## 次の操作

[アプリ内通知](notifications.md)で審査結果を確認し、勤務後は勤務実績の申請分・実績分・差分を確認します。

## トラブル対処

入力単位、事前申請期限、重複、休憩、締め状態が原因で提出できない場合があります。画面の阻害理由を確認し、解消しない場合は[トラブル対処](troubleshooting.md)を参照してください。

## 現行版の制限

時間単位休暇、自動法令判定、多段承認には対応していません。申請・承認は36協定、法定休日労働、割増賃金などの法令や就業規則への適合を判定・保証するものではありません。
