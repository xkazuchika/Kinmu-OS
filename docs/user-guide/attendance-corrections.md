# 勤怠修正の申請と審査

対象バージョン: 0.8.0

## 対象役割と開始画面

従業員は「勤務実績」から申請し、「申請履歴」で状態を確認します。所有者、労務管理者、割り当てられた承認担当者は「承認受信箱」から審査します。

## 従業員が申請する

1. 勤務実績で対象日を選び、「修正を申請」を開きます。
2. 打刻を追加するか、既存の種類・時刻を変更または削除します。
3. 修正理由を入力し、差分を確認して「この内容で申請」を選びます。
4. 状態が「審査待ち」になったことを確認します。

審査待ちまたは差し戻し中の申請は「申請履歴」の詳細から取消できます。申請中は同じ日の新しい申請を重ねて作成できません。

## 管理者が審査する

1. 「承認受信箱」を開き、自分の担当または権限範囲の審査待ち申請を選びます。
2. 修正前と修正後の差分、申請理由、申請時部署、担当、期限、代理作成有無、改訂履歴を確認します。
3. 承認する場合は確認画面を経て承認します。修正できる不足は具体的な理由を付けて差し戻し、終了する場合は理由付きで却下します。
4. 状態と監査ログが更新されたことを確認します。

## 差し戻し、競合、再申請

差し戻されたら「申請履歴」から理由を確認し、希望打刻と申請理由を修正して再申請します。過去版は上書きされず、提出時の内容とactor・時刻が残ります。再申請では現在の打刻、勤務日リビジョン、締め状態、重複を再検証します。前提が変わった場合は保存されないため、最新の勤務実績を確認してください。

管理者が本人から連絡を受けた場合は「代理申請」から作成できます。対象従業員、実際の管理者、代理理由が表示され、代理作成者と対象本人は審査できません。

## 承認後の集計

承認された内容は有効な打刻に反映され、勤務カレンダー、休暇、欠勤を含む日次状態、実労働、残業、勤怠CSVが同じ結果で再集計されます。締め済み月は申請・取消・審査ができないため、管理者が理由を記録して月を再開してから操作します。

## 現行版の制限

時間単位休暇、自動法令判定、多段承認には対応していません。集計と申請承認は法令や就業規則への適合を判定するものではありません。
